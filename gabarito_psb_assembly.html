Q1 — "Copa do Brasil 2026" — Switch-Case com Tabela .DW
Exibir cada caractere de "Copa do brasil 2026" num display de 7-seg.
A tabela .dw guarda os padrões 7-seg dos 14 chars únicos (índices 0x0–0xD).
O mecanismo de desvio é CPI/BREQ encadeados — o professor exigiu essa estrutura de switch-case.

Q2 — Contador 0–59, 2 Displays, 3 Botões
B2 (PD2) zera · B1 (PD1) incrementa +1 · B0 (PD0) decrementa −1
D1 = PORTB (dezena) · D0 = PORTC (unidade) · Pull-up interno ativado
Pull-up: pino repouso = 1, pressionado = 0 → SBIS PIND, BTN pula quando não pressionado.
Underflow: DEC de 0 produz 0xFF → detectar com CPI UNIDADE, 0xFF.
Limite 59: dezena vai de 0–5, unidade 0–9. Checa DEZENA == 6 para resetar.
// DEFINIÇÕES + INICIALIZAÇÕES
.equ DISP_DEZ  = PORTB
.equ DISP_UNI  = PORTC
.equ BTN_DEC   = PD0   ; B0 — decrementa
.equ BTN_INC   = PD1   ; B1 — incrementa
.equ BTN_ZERO  = PD2   ; B2 — zera
.def AUX     = R16
.def DEZENA  = R17
.def UNIDADE = R18

Inicializacoes:
    LDI AUX, 0xFF
    OUT DDRB, AUX          ; PORTB saída (display dezena)
    OUT DDRC, AUX          ; PORTC saída (display unidade)
    LDI AUX, 0x00
    OUT DDRD, AUX          ; PORTD entrada (botões)
    LDI AUX, 0b00000111
    OUT PORTD, AUX         ; pull-up em PD0, PD1, PD2
    LDI DEZENA,  0
    LDI UNIDADE, 0
// LOOP PRINCIPAL + AÇÕES
Principal:
    RCALL Mostrar_Display

    SBIS PIND, BTN_ZERO    ; pula se PD2=1 (solto)
    RJMP Zerar
    SBIS PIND, BTN_INC
    RJMP Incrementar
    SBIS PIND, BTN_DEC
    RJMP Decrementar
    RJMP Principal

Zerar:
    LDI DEZENA,  0
    LDI UNIDADE, 0
    RCALL Debounce
    RJMP Principal

Incrementar:
    INC  UNIDADE
    CPI  UNIDADE, 10
    BRLO Inc_Fim
    LDI  UNIDADE, 0
    INC  DEZENA
    CPI  DEZENA, 6        ; dezena 6 = passou do 59
    BRLO Inc_Fim
    LDI  DEZENA, 0         ; wrap 59 → 00
Inc_Fim:
    RCALL Debounce
    RJMP  Principal

Decrementar:
    MOV  AUX, DEZENA
    OR   AUX, UNIDADE
    BREQ Dec_Wrap          ; se 00 → vai para 59
    DEC  UNIDADE
    CPI  UNIDADE, 0xFF    ; underflow? DEC(0) = 0xFF
    BRNE Dec_Fim
    LDI  UNIDADE, 9
    DEC  DEZENA
Dec_Fim:
    RCALL Debounce
    RJMP  Principal
Dec_Wrap:
    LDI  DEZENA,  5
    LDI  UNIDADE, 9
    RCALL Debounce
    RJMP  Principal
// SUB-ROTINAS + TABELA
Mostrar_Display:
    LDI ZH, HIGH(Tabela<<1)
    LDI ZL, LOW(Tabela<<1)
    ADD ZL, UNIDADE
    BRCC uni_ok  ; sem carry → lê direto
    INC  ZH
uni_ok:
    LPM AUX, Z
    OUT DISP_UNI, AUX

    LDI ZH, HIGH(Tabela<<1)
    LDI ZL, LOW(Tabela<<1)
    ADD ZL, DEZENA
    BRCC dez_ok
    INC  ZH
dez_ok:
    LPM AUX, Z
    OUT DISP_DEZ, AUX
    RET

Debounce:
    RCALL Atraso
Deb_Loop:
    IN   AUX, PIND
    ANDI AUX, 0b00000111
    CPI  AUX, 0b00000111
    BRNE Deb_Loop
    RCALL Atraso
    RET

Atraso:
    LDI R19, 16
volta:
    DEC  R17
    BRNE volta
    DEC  R18
    BRNE volta
    DEC  R19
    BRNE volta
    RET

Q3 — Adaptação do Proj5 para Matriz 10×10
O Proj5 original acessa um array linear com ADD ZL, AUX.
A adaptação recebe LINHA e COLUNA e calcula o índice linear AUX = LINHA×10 + COLUNA antes de passar para Decodifica.
Apenas 4 pontos mudam — o resto é idêntico ao Proj5.
Fórmula:  AUX = LINHA × 10 + COLUNA
Como não há MUL por constante arbitrária:  LINHA×10 = LINHA×8 + LINHA×2 usando shifts (LSL).
// ALTERAÇÃO 1 — novos .def
; === ADICIONADO ===
.def LINHA  = R17   ; índice de linha  (0–9)
.def COLUNA = R18   ; índice de coluna (0–9)
; AUX (R16) continua sendo o índice passado para Decodifica
// ALTERAÇÃO 2 — inicializar linha e coluna
; === ADICIONADO em Inicializacoes ===
    LDI LINHA,  3   ; linha desejada
    LDI COLUNA, 7   ; coluna desejada
// ALTERAÇÃO 3 — Principal: calcula índice linear antes de Decodifica
Principal:
    ; === ADICIONADO — AUX = LINHA*10 + COLUNA ===
    ; LINHA*10 = LINHA*8 + LINHA*2
    MOV  AUX, LINHA        ; AUX = LINHA
    LSL  AUX               ; AUX = LINHA*2

    MOV  R19, LINHA
    LSL  R19               ; R19 = LINHA*2
    LSL  R19               ; R19 = LINHA*4
    LSL  R19               ; R19 = LINHA*8

    ADD  AUX, R19          ; AUX = LINHA*2 + LINHA*8 = LINHA*10
    ADD  AUX, COLUNA       ; AUX = LINHA*10 + COLUNA

    ; === NÃO ALTERADO ===
    RCALL Decodifica
    RCALL Atraso
    RJMP  Principal
// SUB-ROTINAS — não alteradas
; ► Sub-rotina Decodifica — não foi alterada
; ► Sub-rotina Atraso     — não foi alterada
// ALTERAÇÃO 4 — Tabela expandida para 10×10
; === SUBSTITUÍDO — 100 elementos, 50 .dw (row-major) ===
Tabela:
    ; linha 0:  [1][0]   [3][2]   [5][4]   [7][6]   [9][8]
    .dw 0x0100, 0x0302, 0x0504, 0x0706, 0x0908
    ; linha 1
    .dw 0x1110, 0x1312, 0x1514, 0x1716, 0x1918
    ; linha 2
    .dw 0x2120, 0x2322, 0x2524, 0x2726, 0x2928
    ; linha 3
    .dw 0x3130, 0x3332, 0x3534, 0x3736, 0x3938
    ; linha 4
    .dw 0x4140, 0x4342, 0x4544, 0x4746, 0x4948
    ; linha 5
    .dw 0x5150, 0x5352, 0x5554, 0x5756, 0x5958
    ; linha 6

Resumo das 4 alterações: (1) declarar LINHA e COLUNA, (2) inicializá-los, (3) calcular AUX = LINHA×10 + COLUNA no Principal, (4) expandir a Tabela para 10×10. Decodifica e Atraso são intocadas.
